Popotte est un logiciel de gestion de recettes pour Windows, avec une interface simple de type WYSIWYG, pensée pour les débutants comme pour les utilisateurs avancés. Popotte is recipe management software for Windows with a simple WYSIWYG interface, built for beginners and advanced users alike.
